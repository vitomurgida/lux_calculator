# lux_calculator
A simulator computing the light intensity of LED lights

# Introduction and motivation
This repository contains two scripts for calculating the lights intensity generated on the ground of a room by LED strips or tubes.

This code helps in the selection and design of the illumination system of a room such as an office or an hydroponic farm.

# Inputs
- position of the sources
- room dimensions

# Output
- plot of the light intensity on the floor/ground, in lux
